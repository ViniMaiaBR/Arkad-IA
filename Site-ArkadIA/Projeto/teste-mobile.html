Teste de Responsividade Mobile

Este é um arquivo de demonstração para testar a adaptação mobile do site ARKAD AI.

Como Testar:

  • Desktop: Redimensione a janela do navegador para menos de 992px de largura
  • DevTools: Pressione F12 e ative o modo dispositivo móvel (Ctrl+Shift+M)
  • Mobile: Acesse este arquivo diretamente do seu smartphone

O que Observar:

  • Menu hambúrguer aparece no canto superior direito
  • Ao clicar, menu desliza da direita com overlay escuro
  • Botão hambúrguer anima para X quando aberto
  • Clicar fora do menu ou pressionar ESC fecha o menu
  • Scroll do body é bloqueado enquanto menu está aberto
  • Em desktop (>992px), menu volta ao layout horizontal normal

Breakpoints:

  • 992px: Menu hambúrguer ativado
  • 768px: Layout tablet adaptado
  • 576px: Layout smartphone
  • 400px: Ajustes para telas pequenas

Arquivos Envolvidos:

  • css/styles.css - Estilos responsivos e menu hambúrguer
  • js/mobile-menu.js - Lógica do menu mobile
  • Todos os 19 arquivos HTML em /Index

Dica: Abra o console do navegador (F12) para ver mensagens de debug do menu mobile.
